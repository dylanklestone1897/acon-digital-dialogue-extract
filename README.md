## Overview

Acon Digital Extract Dialogue provides audio editors, restoration professionals, and post-production teams with tools for working on speech recordings. It is built around separating spoken content from environmental noise, with support for spectral examination, voice-oriented enhancement, and precise editing.

In version 1.6, adaptive spectral learning works alongside a neural context engine to distinguish speech from noise. Multilingual spectral profiles, multichannel operation, batch WAV handling, and command-line and WebSocket connectivity allow the tool to fit both hands-on editing sessions and repeatable production pipelines.

## Using the Plugin

### Extracting dialogue interactively

1. Bring the dialogue recording into a compatible audio host.
2. Add Acon Digital Extract Dialogue to the appropriate track.
3. Choose a multilingual spectral profile if one is appropriate for the material.
4. Examine the recording in the spectral analysis view to locate voice and noise content.
5. Adjust the extraction and restoration settings while listening to the output.
6. Render or export the cleaned dialogue for subsequent post-production work.

### Processing WAV files in batches

For groups of WAV recordings that need comparable treatment:

1. Place the source WAV files in an input folder.
2. Start the batch-processing workflow.
3. Set the required spectral profile and processing options.
4. Specify the destination folder.
5. Inspect the resulting files and verify metadata retention.

### Building an automated workflow

Command-line access and the WebSocket API can be used to connect the tool to automated pipelines. A workflow may involve:

- Organizing the incoming dialogue recordings
- Choosing a consistent extraction profile
- Running files one at a time or as a batch
- Passing processed audio to the next post-production step
- Checking the resulting metadata and channel arrangement
